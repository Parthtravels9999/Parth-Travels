## 📌 About the Project

This website was developed for **Parth Tours & Travels**, a trusted transportation company based in Ahmedabad, Gujarat.

The website allows visitors to:

* Explore available buses and vehicles
* View vehicle details
* Request a travel quotation
* Contact the company by phone
* Contact the company through WhatsApp
* Learn more about the company
* View business contact information
* Find the company's location

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/darshil-parekh/Parth-Travels.git
```

### 2. Open the project

```bash
cd Parth-Travels
```

### 3. Run the website

You can simply open:

```text
index.html
```

in your browser.

For development, you can also use **VS Code Live Server** or another local web server.

---

## 🌍 Deployment

This website is deployed using **GitHub Pages**.

To deploy your own version:

1. Create a GitHub repository.
2. Upload the project files.
3. Go to **Settings → Pages**.
4. Select the required branch.
5. Select the `/root` folder.
6. Save the configuration.
7. GitHub will generate a public website URL.
